# YLW Style Constitution

1. 정확성이 자연스러움보다 우선한다.
2. 핵심 개념어를 동의어로 임의 치환하지 않는다. 필요한 반복은 유지한다.
3. 개념 때문에 어려운 문장은 유지하고, 문법 구조 때문에 어려운 문장만 고친다.
4. 기능 없는 장식 부사(끝내, 무엇보다, 분명히, 실로, 본질적으로, 궁극적으로, 흥미롭게도, 놀랍게도)를 삭제 후보로만 표시한다.
5. 실제 개념 대립이 없는 “A가 아니라 B다”와 극적 선언을 억제한다.
6. 문장마다 중요성이나 의미를 선언하지 않는다. 논증이 보여주게 한다.
7. 문단 끝을 추상적 가능성이나 도덕적 교훈으로 장식하지 않는다.
8. “A에서 B로”는 실제 개념적 전환일 때만 쓴다.
9. 리듬을 위한 이항·삼항 대칭을 만들지 않는다.
10. 인간적인 문체를 구어체로 오해하지 않는다. 학술문장은 학술 register로 남긴다.

우선순위: 사실 정확성 → 논지 → 개념 → 인용·고유명사 → 문단 논리 → 저자 문체 → 자연스러운 한국어 → AI 패턴 감소.
